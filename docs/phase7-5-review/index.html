Correction guide — examples and punctuation

Write naturally. Full stops, commas, semicolons and new lines are all acceptable. Include the question number and one clear instruction.

  • Marks: 3A calculation; 1A final answer or put each mark on a new line.
  • Subtotal: Question 3 subtotal is 4.
  • Numbering: Rename 11.12.1 to 11.2.1.
  • Conditional marks: 2A for 3 correct answers; 1A for 2 correct answers.

When the actual question or memo answer is wrong, use the structured editor below. It does not depend on punctuation or AI interpretation.
