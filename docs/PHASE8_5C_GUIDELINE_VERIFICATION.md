# Phase 8.5C automatic marking guideline verification

Phase 8.5B keeps its separate evidence and draft interpretation. Phase 8.5C may move routine constructed criteria into the working guideline after GPT-6 Luna independently checks the original crop, question context, working, allocation, ownership and criterion links. The canonical mark records `constructed_verified` provenance. Explicit source instructions retain their original allocation provenance, and confirmed teacher amendments keep their correction audit.

The verifier uses a separate request with the original crop bytes checked against the stored SHA-256. It can propose a bounded repair to a transcription or reconstructed criterion. A second request independently verifies that revised draft against the same image before it can be used. Figure repairs retain the original crop pixels and pass the existing ownership and bounds checks. Repeated source identifiers, unsupported scheme links, inconsistent arithmetic and genuine source conflicts remain reviewable. The deterministic numeric audit continues to distinguish checked results from unsupported expressions.

Positive constructed awards must be linked to real solution observations on the verified crop, maintain explicit allocations, and agree with the printed item total for each genuine working branch. Separate OR branches are tallied by maximum. Approval ticks do not establish marks. The renderer and final DOCX/PDF gates remain unchanged.

The review screen includes the source crop, converted working and editable marking draft for unresolved items. Dependent arithmetic or supporting visual findings wait behind the relevant decisions. No review control confirms a correction automatically.

## Hosted pilot

Use Process Memo on `main` with `operation=revalidate_guideline` for the existing authorised pilot. The operation requires an unrevised Phase 8.5B generation and zero teacher corrections. It archives the complete preceding marking generation, uses an optimistic job claim, and retains original visual regions and earlier archives. It performs no full-document visual read. The shared included-credit ledger is reconciled before inference, and reports only aggregate usage to Actions. A read-only reconciliation can also be run through the hosted qualification workflow.

The review uses the repository’s accepted renderer and marking conventions. The controlled explanatory documents and GOLD memos must be available for direct conformance assessment.
